🚀 Aan de slag

CorioTEC DrawingVault is een professioneel tekeningen­beheersysteem. Data wordt lokaal opgeslagen in de browser. Gebruik de auto-backup om regelmatig een JSON-bestand te bewaren.

☰ Menu (hamburger)

Alle acties zitten in het ☰ menu rechtsboven: map openen, upload, audit log, disciplines, gebruikersbeheer, backup en accountinstellingen. De CAD voorkeur (interne viewer of systeem­programma) staat ook in dit menu.

+ Nieuwe Tekening

Klik op + Nieuwe Tekening. Vul nummer, revisie, titel, discipline en project in. Voeg optioneel een PDF- of CAD-bestand toe.

Revisies beheren

Open het detailpaneel (klik op een kaart) → ✏️ Bewerken. Voer de nieuwe revisieletter in (A→B→C…). Alle vorige revisies blijven bewaard.

CAD bestanden openen

Klik op 📂 op een tekenkaart. Dialoog toont aanwezige bestanden:
• Alleen PDF → keuze: preview of systeem PDF-viewer
• DWG/DXF aanwezig → keuze: interne CAD viewer of downloaden voor AutoCAD
Voorkeur instellen via ☰ → CAD instellingen.

Selectie & verplaatsen

Klik op tekstblok of vinkje. CTRL+A selecteert alles. Sleep rechthoek (links→rechts = volledig, rechts→links = aanraken). Sleep naar discipline in zijbalk. SHIFT+klik heft selectie op.

Disciplines beheren

Via ☰ → 🏷 Disciplines beheren. Toevoegen, hernoemen, icoon wijzigen of verwijderen. Alle disciplines zichtbaar in zijbalk — ook lege.

Auto-backup & database laden

Via ☰ → 💾 Auto-backup. Kies map, stel interval in. Gebruik 🔍 Scan om databases in de backup­map te tonen. Per naam alleen de nieuwste versie. Kies en klik 📂 Laden.

⚙️ Installatie Beschrijving

Vereisten

CorioTEC DrawingVault is een standalone HTML5-applicatie. Er is geen server, database of installatie vereist.

Minimale vereisten
✓ Moderne browser (Chrome 90+, Firefox 88+, Edge 90+, Safari 14+)
✓ JavaScript ingeschakeld
✓ localStorage beschikbaar (~5MB per domein)
✗ Geen internet vereist (offline-capable)
Lokaal draaien
# Open het bestand direct in je browser
$ open index.html

# Of via een lokale server (aanbevolen)
$ npx serve .
$ python3 -m http.server 8080
Server deployment
# Nginx configuratie
server {
  listen 80;
  root /var/www/drawingvault;
  index index.html;
  add_header X-Frame-Options DENY;
  add_header X-Content-Type-Options nosniff;
}

# Docker
$ docker run -p 80:80 -v $(pwd):/usr/share/nginx/html nginx
Data backup

Gebruik CorioTEC DrawingVault.export() in de browser console om een JSON-backup te maken. Importeer met CorioTEC DrawingVault.import(jsonString).
